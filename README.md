# Student Task Manager

This is a simple web project created for the Software Engineering course.

## Project Description

Student Task Manager is a small website that helps students manage their daily study tasks.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Simple and clean user interface

## Tools Used

- HTML
- CSS
- JavaScript
- Git
- GitHub
- Postman
